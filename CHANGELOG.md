# Changelog

Version format: `major.minor.patch` with a two-digit patch (0.4.00). Tags on GitHub: `v0.4.00`.

## 0.4.00 – 2026-10-21

First numbered release; everything built so far:

- Always-on-top panel with several focuses, switching, time per focus, color per focus, rename, note
  ("where did I leave off"), done/delete with undo.
- Collapsed view (active focus + dots), expand on click, top-anchored window that remembers its position
  per display arrangement.
- Pause/resume on screen lock and sleep, inactivity nudge, idle dimming while paused (click to wake).
- Templates and "recently finished" suggestions when adding a focus.
- Global shortcuts, menu bar item with switching/undo/log, log window, Do Not Disturb via Shortcuts.
- Settings with sidebar: general (limit, size, language), templates, shortcuts, behavior (nudge, window,
  calendar, DND), sync (state.json in a cloud folder), about (version, donation).
- English and Slovenian. Source-available freeware license, PayPal donations.
